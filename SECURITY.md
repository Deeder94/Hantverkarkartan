# Security and privacy reports

För felaktig eller känslig företagsinformation eller misstänkt personuppgiftsincident: kontakta operatören via e-postadressen på integritetssidan. Publicera inte personuppgifter i GitHub-ärenden. Ange företagsreferensen som visas under datakällan. Vid befogade begäranden kan posten undantas via assets/listing-suppression.js och en ny publicering. Kontrollera båda tjänsterna och kontakta Overture separat för källdata. GDPR-begäranden besvaras normalt inom en månad, med lagliga undantag.
